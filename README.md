# Домашнє завдання: JavaScript

Це домашнє завдання з JavaScript, яке складається з кількох завдань для закріплення базових концепцій роботи з об'єктами, функціями та умовними операторами.

## Завдання:

### 1. Об'єкт користувача

Створіть об'єкт `userObj`, який містить поля:
- `firstName` (ім'я, рядок)
- `lastName` (прізвище, рядок)
- `age` (вік, число)

### 2. Метод для повного імені

До об'єкта з попереднього завдання додайте метод `fullName()`, який повертає повне ім'я (конкатенація `firstName` та `lastName`).

### 3. Функція для перетворення в верхній регістр

Створіть функцію `defUpperStr(str)`, яка приймає параметр і повертає його в верхньому регістрі. Якщо функція викликається без параметра, вона повинна повернути текст "DEFAULT TEXT" в верхньому регістрі.

### 4. Функція для парних чисел

Створіть функцію `evenFn(n)`, яка приймає число `n` і повертає масив з парних чисел від 1 до `n` (включно).

### 5. Функція для дня тижня

Створіть функцію `weekFn(n)`, яка приймає номер дня тижня та повертає його назву. Якщо введено некоректне значення, функція має повернути `null`.

### 6. Функція для класифікації віку

Створіть функцію `ageClassification(n)`, яка класифікує вік за наступними категоріями:
- Менше 0: `null`
- 0-24: "Дитинство"
- 25-44: "Молодість"
- 45-65: "Зрілість"
- 66-75: "Старість"
- 76-90: "Довголіття"
- 91-122: "Рекорд"
- Більше 122: `null`

### 7. Функція для непарних чисел

Створіть функцію `oddFn(n)`, яка приймає число `n` і повертає масив з непарних чисел від 1 до `n` (включно), використовуючи лише цикл `while`.

### 8. Функція з колбеком

Створіть основну функцію `mainFunc(a, b, callback)`, яка приймає два числа і колбек-функцію, яка опрацьовує ці числа. Якщо переданий не функція, повертається `false`.

#### Колбек-функції:
- `cbRandom(a, b)` — генерує випадкове ціле число між `a` та `b`.
- `cbPow(a, b)` — підносить число `a` до степеня `b`.
- `cbAdd(a, b)` — обчислює суму чисел `a` та `b`.

## Тестування

Для кожного з завдань передбачено тестування, де перевіряються правильність виконання функцій. Ви можете протестувати їх, використовуючи вбудовані `console.log()`.

## Підсумок

Це домашнє завдання дозволяє потренуватися в основах роботи з функціями, умовними операторами та маніпуляцією з масивами. Завдання дають змогу зрозуміти, як працювати з об'єктами та методами в JavaScript, а також як обробляти дані за допомогою різних типів функцій.
